    Facilitator notes
    Start with a question. Ask learners to predict the result, edit a small function, then run the experiment. Name the concept after they see it work.
    1. Tasks 00–02 / Create the machine: boot identity, process records, memory limits.
    2. Tasks 03–05 / Share CPU time: compare FCFS, SJF and Round Robin on identical jobs.
    3. Tasks 06–09 / Handle the messy parts: blocking I/O, interrupts, mutual exclusion and lock ordering.
    4. Tasks 10–11 / Make it usable: files, a shell, and a bootable export.
    Allow 75–100 minutes with pair discussion. For a quick walkthrough, prepare a facilitator build. Students use the tutor checkpoint and explain their evidence before consulting a reference. These time estimates are planning suggestions, not a timed requirement.
    Edits mark that module as unverified. Rerun it before exporting. Progress is saved in this browser when local storage is available. The export contains verified code and runs offline.
    Every task runs Python through the bundled offline Skulpt runtime in a time-limited worker. Basic Python is supported; this is not a complete desktop Python installation. The starter deliberately fails; Run reports the problem. Student checkpoints collect a prediction, observation and question.
